# Imagens do site

Esta pasta guarda as imagens utilizadas nas páginas do Dr. Pedro Simplício.

## Foto principal do banner

Envie aqui o arquivo PNG original com o nome exato:

`hero-reabilitacao.png`

O `index.html` já aponta para `/assets/hero-reabilitacao.png`. A foto será exibida automaticamente depois que o GitHub e o Vercel concluírem a publicação.

**Importante:** use o PNG original em alta resolução. Não renomeie um WebP comprimido para PNG.
